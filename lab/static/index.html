Sorting cell lab

a UR5e and a Robotiq gripper sort YCB recyclables off a moving belt, built phase by phase on this Mac

What this is

A virtual recycling cell: mixed items ride a conveyor belt, a robot arm picks each one and drops it in the chute for its material (plastic, metal, cardboard) before it leaves the reach zone. The belt never stops, so every pick has a deadline. The project builds it the way a robotics engineer would: first a classical pipeline with no learning at all (geometry, planning, control), then learning wherever it measurably beats the classical module. Each phase below has a page that explains the idea, shows what was built and measured, and lets you run it yourself.

The pipeline

Sense along the top, decide on the right, act along the bottom, all on a simulated cell. Highlighted boxes are finished; click a box for its phase.
